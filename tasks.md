# Практические задания

**Тема:** Агрегатные функции SQL

## Лёгкая — Подсчет общего количества записей

### Условие

Представьте, что у вас есть таблица `orders` со следующими столбцами:
- `order_id` (INT, PRIMARY KEY)
- `customer_id` (INT)
- `order_date` (DATE)
- `total_amount` (DECIMAL(10, 2))

Напишите SQL-запрос, который подсчитает общее количество заказов в таблице `orders`.

### Что сдать

SQL-запрос.

### Критерии проверки

Запрос должен использовать агрегатную функцию для подсчета строк и возвращать одно числовое значение.

## Средняя — Средняя сумма заказа по каждому клиенту

### Условие

Используя ту же таблицу `orders` (столбцы: `order_id`, `customer_id`, `order_date`, `total_amount`), напишите SQL-запрос, который вычислит среднюю сумму заказа для каждого клиента. Результат должен содержать `customer_id` и среднюю сумму его заказов (`average_order_amount`).

Таблица: `orders`
Столбцы: `order_id`, `customer_id`, `order_date`, `total_amount`
Ключ связи: нет (запрос работает с одной таблицей)

### Что сдать

SQL-запрос.

### Критерии проверки

Запрос должен использовать агрегатную функцию `AVG` и группировку по `customer_id`. Результат должен содержать `customer_id` и вычисленную среднюю сумму заказа. Дополнительно, подсчитайте количество заказов для каждого клиента (`order_count`).

## Сложная — Максимальная сумма заказа и количество заказов за месяц с обработкой граничных случаев

### Условие

Используя таблицу `orders` (столбцы: `order_id`, `customer_id`, `order_date`, `total_amount`), напишите SQL-запрос, который для каждого месяца (год и месяц) определит максимальную сумму заказа (`max_order_amount`) и общее количество заказов (`total_orders_in_month`).

Таблица: `orders`
Столбцы: `order_id`, `customer_id`, `order_date`, `total_amount`
Ключ связи: нет (запрос работает с одной таблицей)

**Граничный случай:** Если в каком-либо месяце нет заказов, этот месяц не должен быть включен в результат. Если в месяце есть заказы с одинаковой максимальной суммой, любая из них может быть выбрана как максимальная.

### Что сдать

SQL-запрос.

### Критерии проверки

Запрос должен извлекать год и месяц из `order_date`. Должны использоваться агрегатные функции `MAX` и `COUNT`. Результат должен быть сгруппирован по месяцу. Запросы для месяцев без заказов должны быть исключены. Обработка NULL значений в `total_amount` не требуется, предполагается, что они отсутствуют или обрабатываются на уровне приложения.
