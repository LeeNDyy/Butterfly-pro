# Butterfly-pro

Терминальный помощник преподавателя. Требуется Python 3.9 или новее. Команды ниже запускаются из корня проекта.

## Чат в терминале

```sh
python3 main.py chat
```

Можно писать обычным языком. После ответа помощник помнит последний комплект, поэтому можно попросить его усложнить или упростить задачу.

```text
Вы → Составь задачи по SQL для начинающих
Вы → Усложни среднюю задачу
Вы → /save sql-tasks.md
Вы → /source test_source.txt
Вы → /work test_work.txt
Вы → Проверь работу
Вы → /exit
```

Текст можно передать прямо в сообщении «Проверь: текст работы». Команда `/help` показывает подсказку.
`/demo` проверяет готовый пример. `/status` показывает прикреплённые файлы и тему последнего комплекта.

## Проверка текста

```sh
python3 main.py check --file работа.txt --source источник.txt
python3 main.py check --text 'Текст работы из пяти или более слов' --source конспект.txt --source методичка.txt
cat работа.txt | python3 main.py check --stdin --source источник.txt
```

Уникальность — доля слов работы, которые не входят ни в одно дословное совпадение из пяти последовательных слов с указанными источниками. Сравнение игнорирует регистр, пунктуацию и различие между «е» и «ё». Проверка выполняется локально. Покрытие ограничено переданными источниками. Перефразирование, корректность цитирования и авторство требуют отдельной оценки преподавателя.

## Генерация задач

В `.env` укажите `SPRUTDOCK_API_KEY`. Пример настроек лежит в `.env.example`. Приложение также читает ключ из переменной окружения, а для совместимости с предоставленным файлом принимает имя `B_AI_API_KEY` в локальном `.env`. Во всех случаях значение должно быть ключом SprutDock.

```sh
python3 main.py generate 'Агрегатные функции SQL для начинающих' -o sql-tasks.md
```

Команда делает один запрос к SprutDock и сохраняет три задания — лёгкое, среднее и сложное. У каждого есть условие, результат для сдачи и критерии проверки. По умолчанию используется модель `google/gemini-2.5-flash-lite` и файл `tasks.md`. Модель можно поменять через `SPRUTDOCK_MODEL`. Для записи выбирайте новое имя файла в существующем каталоге.

## Критерии проверки

| Сценарий | Ожидаемый результат |
| --- | --- |
| Текст целиком совпадает с источником | Вердикт о полном совпадении, уникальность 0% |
| Совпала часть текста | Вердикт о совпадениях, процент по доле несовпавших слов |
| Совпадений в указанных источниках нет | Уникальность 100% относительно этих источников |
| Генерация по учебной теме | Markdown с тремя уровнями сложности |
| Ответ модели неполный или файл уже существует | Ошибка, существующий файл сохраняется |
